# Udemy Clone Website 🎓

A responsive Udemy Clone website built using **HTML5 and CSS3**. This project recreates the basic design and layout of the Udemy online learning platform, providing a clean and user-friendly interface for exploring online courses.

## 🚀 Features
- Clean and attractive user interface
- Navigation bar and search section
- Course categories and course cards
- Responsive page layout
- Custom styling using CSS
- Structured webpage using HTML5

## 🛠️ Technologies Used
- **HTML5** – Website structure
- **CSS3** – Styling, layouts, colors, and visual design

## 🎯 Project Objective
The main objective of this project is to improve my front-end web development skills by creating an educational website interface inspired by Udemy.

## 💻 How to Run
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
